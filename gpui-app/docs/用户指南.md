# 字笺 · Typst 用户指南

字笺是一个在本机运行的 Typst 编辑器：左边是文稿卡片和目录，中间是稿纸编辑器，右边是实时预览。文稿只保存在你的电脑上，不会上传。

## 开始

1. 双击 `Zijian-…-Setup.exe`，按向导安装，然后从开始菜单启动“字笺 · Typst”。安装到当前用户，无需管理员权限，可选创建桌面快捷方式。也可解压便携 ZIP，双击 `typst-editor-gpui.exe`。
2. 欢迎页可以：
   - **新建项目**：选一个文件夹名，字笺会在里面创建 `main.typ`；
   - **打开文件夹**：打开已有的 Typst 项目（有 `typst.toml` 时以它所在目录为项目根）；
   - **打开文件** 或 **排版示例**。
3. 下次启动会自动回到上次的项目和标签页。“文件 → 最近项目”可以切换项目。

安装向导可选将字笺添加到 `.typ` 文件的“打开方式”，不会强制替换默认编辑器。更新时运行新版安装包覆盖安装，设置和草稿会保留。卸载请到 Windows“设置 → 应用 → 已安装的应用”找到“字笺 · Typst”；卸载保留文稿、设置和恢复草稿。

## 界面

| 区域 | 用途 |
|---|---|
| 顶栏 | 菜单、项目名（点击可切换文稿）、新建 / 打开 / 保存 / 重新编译 / 导出 / 文稿栏 |
| 文稿栏 · 文稿 | 每个 `.typ` 一张卡片。图钉 = 固定为预览主文件（再点一次取消）；星标 = 置顶；“入口”表示自动选择的主文件 |
| 文稿栏 · 文件 | 完整目录树。右键可新建文稿 / 文件夹、重命名、在资源管理器中显示、移到回收站 |
| 目录卡 | 文档标题，点击跳转；可拖动分界线调整高度，点标题栏折叠 |
| 稿纸 | 每个标签页都有自己的撤销记录、光标和滚动位置。视图菜单可切换“紧凑代码模式（行号）”和字号 |
| 预览 | 点击文字跳回源码；“适宽”让页面随栏宽缩放，百分比按钮恢复实际大小 |
| 状态栏 | 编译指示灯、问题数（点击打开问题列表）、保存状态、行列、字数、页数 |

## 字体设置

通过 **视图 → 设置…** 或 **Ctrl+,** 打开字体设置面板。

- **界面字体**：设置菜单、文稿栏和各面板使用的字体。
- **编辑器字体**：设置源码字体，可搜索本机已安装字体，建议选用等宽字体。
- **编辑器字号**：使用 − / + 在 11–24 px 之间调整，面板内可实时预览。

修改立即生效并自动保存，重启后沿用。“恢复默认字体”恢复自动选字和 15 px 编辑器字号。已选字体被卸载时会自动回退到可用字体。
这些设置不改变预览和导出文档的排版字体；文档字体请在 Typst 源码中用 `#set text(font: ...)` 设置。

## 保存与文稿安全

- **保存是原子的**：先写同目录临时文件，确认写入后再替换原文件。保存中途断电或出错不会留下半个文件。
- **外部修改**：其他程序改了已打开的文件时——
  - 字笺里没有未保存修改：自动载入新内容（仍可撤销）；
  - 有未保存修改：稿纸顶部出现提示，选择“载入磁盘版本”或“保留我的版本”。
  - 保存时如果磁盘上已有新内容，会先询问，**不会静默覆盖**。
- **保存失败**（只读、没有权限、磁盘满）：修改留在编辑器中，稿纸顶部的红色提示条会一直显示，直到“重试保存”或“另存为”成功。
- **崩溃恢复**：未保存的文本会在停止输入约 1 秒后写入恢复草稿。字笺异常退出后，下次启动会询问是否恢复。恢复的内容以“未保存”状态打开，确认后再保存。
- **关闭提示**：切换项目、关闭标签或退出时，如有未保存修改会先询问。

## 编译与预览

- 输入后约 0.1 秒自动重新编译。F5 为强制重新编译（忽略缓存）。
- 编辑被引用的章节时，会自动编译引用它的主文件；也可用卡片上的图钉固定主文件。
- 被引用但未打开的文件在磁盘上被修改时，预览会自动更新。
- **导出 PDF** 时会先用当前文本重新确认编译结果，导出的始终是当前主文件。

## 模板包（@preview）

`#import "@preview/包名:版本"` 首次使用时会从 Typst Universe 下载到本机缓存
（Windows 上为 `%LOCALAPPDATA%\typst\packages`），之后离线也能使用。
离线时首次使用会报“无法下载”，联网后按 F5 重试即可。本地包目录（`%APPDATA%\typst\packages`）中的包优先使用。

## 查找与替换

- Ctrl+F / Ctrl+H：在当前文稿中查找 / 替换。
- Ctrl+Shift+F：在整个项目中查找；“全部替换”只修改编辑器中的文本（可撤销），确认后再保存。
- 侧栏搜索框只按文件名、卡片标题和目录标题过滤，不是全文搜索。

## 常见问题

| 现象 | 处理 |
|---|---|
| 预览没有更新 | 看状态栏指示灯：红色表示有错误，点击问题数查看；F5 强制重新编译 |
| `unknown variable` / `file not found` | 检查拼写和相对路径；被引用文件需在项目根目录内 |
| 包下载失败 | 检查网络或代理；联网后 F5 |
| 字体与预期不同 | 字笺只使用本机已安装字体和 Typst 自带字体；在文稿中用 `#set text(font: ...)` 指定已安装字体 |
| 保存失败 | 看稿纸顶部提示：只读文件请取消只读或“另存为” |

## 数据与隐私

字笺的数据都在本机：

| 内容 | 位置（Windows） |
|---|---|
| 设置、最近项目、上次会话 | `%LOCALAPPDATA%\Zijian\settings.json` |
| 崩溃恢复草稿（保存或关闭后删除） | `%LOCALAPPDATA%\Zijian\recovery\` |
| 日志与崩溃报告 | `%LOCALAPPDATA%\Zijian\logs\` |

日志只记录事件、路径和错误信息，不记录文稿内容。“帮助 → 复制诊断信息”复制版本、平台和日志末尾，可直接贴进问题反馈。
可设置环境变量 `ZIJIAN_DATA_DIR` 把这些数据放到其他位置。

唯一的网络访问是首次使用 `@preview` 模板包时从 Typst Universe 下载。

## 更新与卸载

- **更新**：退出字笺，用新版本文件夹替换旧版本。设置和草稿在数据目录中，会被新版本沿用；设置文件中新版本不认识的项会被忽略，缺失的项使用默认值。
- **卸载**：删除程序文件夹；如需同时清除设置和日志，删除 `%LOCALAPPDATA%\Zijian`。
